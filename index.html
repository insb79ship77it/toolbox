💡 IP 주소 및 위치 조회 가이드

IP 주소(Internet Protocol Address)는 인터넷에 연결된 컴퓨터나 단말기가 서로를 식별하고 통신하기 위해 부여받는 고유한 네트워크 번호입니다.

공인 IP vs 사설 IP

  • 공인 IP (Public IP): ISP(통신사)가 부여하며, 인터넷 상에서 유일하게 식별되는 외부 접속용 주소입니다.
  • 사설 IP (Private IP): 공유기 내부에서 각 기기(스마트폰, PC 등)에 할당되는 내부 주소입니다.

  • 한글/한자: UTF-8 인코딩 기준 1글자당 3 Byte
